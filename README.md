# Klinik-IT: AD und baramundi Automationen

Nachvollziehbare PowerShell-Beispiele für lokales Active Directory und Endpoint-Inventare. Alle Beispiele verwenden ausschließlich synthetische Daten und liefern Prüfkandidaten für verantwortliche Administratoren.

## Einstieg

- Wochenpakete: `automations/`
- Fachbeiträge mit Primärquellen: `articles/`
- [Sicherheitsmodell](docs/safety-model.md)
- [Laborprüfung](docs/lab-validation.md)

Vor jeder Nutzung Quellcode prüfen, im isolierten Labor testen und lokale Freigaben beachten. Dieses Portfolio ersetzt weder eine vollständige Asset-Erfassung noch eine betriebliche Risikoentscheidung.
