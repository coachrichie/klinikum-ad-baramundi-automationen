# Sicherheit

Dieses Repository enthält Portfolio-Beispiele und keine produktionsfreigegebenen Kliniklösungen. Keine Zugangsdaten, realen Gerätenamen, Exportdateien oder personenbezogenen Daten veröffentlichen.

Sicherheitsprobleme bitte über GitHubs private Schwachstellenmeldung melden, sofern aktiviert. Andernfalls zunächst ein öffentliches Issue ohne sensible Details zur sicheren Kontaktaufnahme eröffnen. Keine produktiven Daten oder ausnutzbaren Geheimnisse in Issues einfügen.

Die Sicherheitsgrenzen jedes Wochenpakets und `docs/safety-model.md` gelten vor einer Nutzung. Automatische Änderungen an AD- oder Endpoint-Systemen benötigen eine gesonderte Entwicklung und Freigabe.
